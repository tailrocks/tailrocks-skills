# Item seeding

Create one content-derived `roadmap/<slug>/README.md` in `DRAFT` with source,
problem, verified evidence, desired outcome, constraints, decisions, open
questions, remaining work, and next command. Add exactly one sorted index row,
creating the index only when the first live item enters the board.

Open or reuse the item's one delivery branch and draft pull request. Do not add
`plan/`, `goal/`, or verification files: later delivery owners create those only
after shaping and readiness.
