# Project Contract Discovery

Read every discovered policy file in full. Record source path, immutable
revision or response identity, hash, and checked time.

1. **Channel:** canonical forge, mailing list, review system, or governance
   venue; pointer and maintainer files win over assumptions.
2. **Liveness:** recent changes/releases, external-change latency, response time,
   abandoned queues, and open contribution caps.
3. **License/legal:** repository and file exceptions; signoff/agreement evidence;
   every legal act remains human-only.
4. **Contribution and conduct:** root, metadata, documentation, templates,
   governance, and behavioral requirements.
5. **Assistance policy:** classify `BAN`, `DISCLOSURE_REQUIRED`, `CONDITIONAL`,
   or `SILENT`; silence never waives disclosure or other rules.
6. **Security:** declared private reporting location and prohibited public paths.
7. **Scale/issue norm:** proposal gates, claim/assignment rules, newcomer
   reservations, prior attempts, and accepted direction.
8. **Templates/owners:** issue and change forms, chooser config, ownership and
   contention. Configuration is not itself a body template.
9. **History/tooling:** commit, revision, base/merge, changelog, build, test,
   lint, format, and local instruction regimes verified from current evidence.

The report contains target and source identities, classifications, red flags,
allowed next venue, exact proven commands, and concrete alternatives. Missing or
stale evidence is `UNKNOWN`, never inferred permission.
