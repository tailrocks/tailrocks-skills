# Alpha Focus

Start the timer with the session length, enable the system focus mode,
and begin the interruption log.

Never end the timer early without logging the reason — an unlogged early
stop is the failure this skill exists to prevent, and skipping the log
entry makes the session review worthless.

When the timer ends, disable focus mode and append the session summary to
the log.
