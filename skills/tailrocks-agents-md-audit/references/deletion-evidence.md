# Rule deletion evidence

Propose deletion only when evidence shows one of: a named gate/type/linter now
enforces the constraint; the governed subject no longer exists; a current
instruction higher in the load chain duplicates it exactly; or a documented
model workaround is obsolete and current behavior was directly verified.

“Looks obvious,” age, size alone, and absence of a remembered incident are not
deletion evidence. Cite the exact rule and the enforcing, dead, duplicate, or
verified replacement surface. Audit proposes deletion; sync applies it only when
the active task explicitly approves that exact rule removal.
