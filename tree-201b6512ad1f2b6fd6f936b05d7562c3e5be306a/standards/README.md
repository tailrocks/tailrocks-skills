# Shared standards

This directory holds the common structure and writing rules.
All Tailrocks packages obey these rules.
The marketplace owns these files.

[structure.md](structure.md) gives the required repository structures.
It covers active packages, marketplace additions, and retired
repositories.
It also gives manifest rules, skill body order, and README order.

[writing.md](writing.md) gives the shared writing guide.
It lists the 15 strict ASD-STE100 Issue 9 rules.
It also gives term meanings and software verb meanings.
