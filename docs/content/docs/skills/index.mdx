### Roadmap and delivery

An idea through shaping, planning, autonomous execution, and back to verified truth.

| Skill | What it does |
|---|---|
| [`tailrocks-idea`](/docs/skills/tailrocks-idea) | Capture a raw product or feature idea as a new roadmap item: derive a slug from the content, create roadmap/&lt;slug>/README.md in DRAFT status from the item template, and register it in the roadmap index. |
| [`tailrocks-brainstorm`](/docs/skills/tailrocks-brainstorm) | Shape a DRAFT or SHAPING roadmap item through a relentless interview: one question at a time with a recommended answer, decisions asked while facts are looked up, every resolved answer written into the item immediately. |
| [`tailrocks-research`](/docs/skills/tailrocks-research) | Run deep, sourced research into a reusable topic folder under research/: either a specific question ("pure-Rust macOS app without Swift") or a roadmap item to extend — surfacing missed angles, directions, and evidence. |
| [`tailrocks-record-decision`](/docs/skills/tailrocks-record-decision) | Record one user decision on a roadmap item: validate it against settled ground, date it with its reason, propagate it through the item's sections, and flag everything it invalidates — including reopening READY/PLANNED items and marking stale plans. |
| [`tailrocks-finalize`](/docs/skills/tailrocks-finalize) | Finalize a SHAPING roadmap item through a closing interview: collect every screen and flow, resolve or classify every open question, verify the readiness checklist, and set the item READY for planning. |
| [`tailrocks-plan`](/docs/skills/tailrocks-plan) | Convert a READY roadmap item into the full implementation package under plans/&lt;slug>/: coverage ledger, gap-filling research, an OpenSpec-grammar spec, one zero-context plan per work item — each written by its own subagent and cold-reviewed — plus a copy-pasteable GOAL.md for Claude Code and Codex goal execution or manual Grok prompting. |
| [`tailrocks-reconcile`](/docs/skills/tailrocks-reconcile) | True up an implementation package under plans/&lt;slug>/ with execution reality: re-verify DONE rows by re-running their done criteria, reset or salvage IN PROGRESS rows left by dead sessions, investigate BLOCKED rows, drift-check TODO plans against HEAD, mark stale rows with reasons, and reconcile the roadmap item's status. |
