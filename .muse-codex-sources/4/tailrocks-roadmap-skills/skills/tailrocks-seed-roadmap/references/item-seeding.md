# Item seeding

Create one content-derived `roadmap/<slug>/README.md` in `DRAFT`
with source, problem, verified evidence, desired outcome,
constraints, decisions, open questions, remaining work, and the
next command. Add exactly one sorted index row. Create the index
only when the first live item enters the board.

Open the one delivery branch and draft pull request of the item,
or reuse the lane in place. Do not add `plan/`, `goal/`, or
verification files. Later delivery owners create those files only
after shaping and readiness.
