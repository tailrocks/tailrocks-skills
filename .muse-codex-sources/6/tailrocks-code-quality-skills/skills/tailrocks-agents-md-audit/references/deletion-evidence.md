# Rule deletion evidence

Propose deletion only when evidence shows one of these states:

- A named gate, type check, or linter now enforces the
  constraint.
- The governed subject no longer exists.
- A current instruction higher in the load chain duplicates the
  rule exactly.
- A documented model workaround is obsolete and current
  behavior was directly verified.

Obvious appearance, age, size alone, and absence of a remembered
incident are not deletion evidence. Cite the exact rule and the
enforcing, dead, duplicate, or verified replacement surface. Audit
proposes deletion. Sync applies it only when the active task
explicitly approves that exact rule removal.
