# Rule writing

A line is eligible only when a competent agent with the repository
and no instruction file can plausibly violate it. The violation
needs concrete evidence. Route formatter, linter, type, schema,
and validator rules to enforcement. Route repeatable procedures to a
skill. Route explanations to documentation. Route permissions to
settings.

Write one imperative sentence. Remove hedging, preamble, and
filler. Preserve `not`, `never`, `no`, `only`, `except`,
identifiers, commands, paths, versions, units, and exact error
strings. Add the mechanism only when the rule otherwise appears
arbitrary. Refuse a rule without an observable violation.
