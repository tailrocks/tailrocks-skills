# Standalone-plan eligibility

A finding is eligible only when every item below holds:

- One fresh executor session can complete it
- Confidence is HIGH
- Fix risk is LOW
- No product or architecture decision remains
- Current evidence is sufficient.

Effort can be S or M. It never overrides risk.
LOW confidence produces an investigation plan, not a fix
plan. L scope, direction work, security-boundary uncertainty,
and any MEDIUM or HIGH fix risk route to
`tailrocks-seed-roadmap`.
