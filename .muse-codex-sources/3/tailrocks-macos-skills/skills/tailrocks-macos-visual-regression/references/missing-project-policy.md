# Missing-project policy

A missing runnable project blocks execution, never policy. Do not install a
harness, build a fixture, create a baseline, write project files, or change real
system settings merely to simulate evidence.

Return the exact unexecuted build, capture, interaction, state-matrix,
accessibility-audit, restoration, and final-identity procedure. Account for
every required state with the specific evidence still owed. A user-reported run
is attributed as reported evidence; it is never presented as locally executed
proof.
