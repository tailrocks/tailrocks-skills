# Project Contract Discovery

Read every discovered policy file in full. Record source path,
immutable revision or response identity, hash, and checked time.
Classify each row below:

1. **Channel:** canonical forge, mailing list, review system, or
   governance venue.
2. **Liveness:** recent changes and releases, external-change latency,
   response time, abandoned queues, and open contribution caps.
3. **License and legal acts:** repository license and file exceptions,
   signoff and agreement evidence.
4. **Contribution and conduct:** root, metadata, documentation,
   templates, governance, and behavioral requirements.
5. **Assistance policy:** `BAN`, `DISCLOSURE_REQUIRED`, `CONDITIONAL`,
   or `SILENT`.
6. **Security:** declared private reporting location and prohibited
   public paths.
7. **Scale and issue norm:** proposal gates, claim and assignment
   rules, newcomer reservations, prior attempts, and accepted
   direction.
8. **Templates and owners:** issue and change forms, chooser config,
   ownership and contention.
9. **History and tooling:** commit, revision, base and merge,
   changelog, build, test, lint, format, and local instruction regimes
   from current evidence.

Pointer and maintainer files win over assumptions. Silence never
waives disclosure or other rules. Configuration is not a body
template. Every legal act remains human-only. Missing or stale
evidence is UNKNOWN. Never infer permission.

The report holds target and source identities, classifications, red
flags, the allowed next venue, exact proven commands, and concrete
alternatives.
