## Finding

The repository currently has one universal invocation class: all 43 skills are
manual-only. The rule is declared in `AGENTS.md:48-55`, documented in
`INSTALL.md:202-211`, generated by `scripts/generate-docs.ts:314-316`, and
enforced by `scripts/validate-skills.ts:286-315`. Every published skill carries
`disable-model-invocation: true`, `user-invocable: true`, and Codex
`policy.allow_implicit_invocation: false`.

That universal rule conflicts with the role of passive policy skills. The six
language/transport best-practices skills are correctness lenses that should load
when matching code is already in scope. Their invocation grants no new mutation
or external authority. `tailrocks-review-pr` already dispatches all six by
changed content at `skills/tailrocks-review-pr/SKILL.md:72-85`.

## Invocation classes

Use three repository-owned classes:

1. **MANUAL_ONLY** — a transaction or workflow the user must deliberately
   start. The model may recommend it but does not select it.
2. **MODEL_POLICY** — passive background knowledge selected automatically by an
   exact content predicate. It grants no authority beyond the active task.
   Hiding manual invocation is best-effort because client semantics differ.
3. **DUAL** — a natural-language intent may select it automatically and a user
   may also invoke it by name.

Do not call `MODEL_POLICY` “model-only” as a portable guarantee. Some clients
can hide direct invocation while retaining model discovery; others cannot. The
repository can guarantee model discoverability, not identical menu behavior.

## Proposed `tailrocks-grilling` contract

Single responsibility: interrogate a user-requested idea as a
dependency-ordered decision tree.

- Ask only decisions whose prerequisites are settled.
- Give a recommendation with every question.
- Retrieve environmental facts independently, using subagents where useful.
- Leave product/value decisions to the user.
- Recompute the frontier after every answer round.
- Do not execute the idea until the frontier is empty and the user confirms
  shared understanding.

This is conversation-only. It writes no roadmap artifacts, changes no status,
and grants no execution authority. `tailrocks-brainstorm` remains manual-only
because it persists decisions, changes roadmap state, commits, and pushes.
